OVERVIEW

What is Telegraf?

01 / 10

Telegraf ialah framework Node.js yang membantu developer membina Telegram Bot dengan lebih mudah melalui Telegram Bot API.

01

Simple API

Gunakan method yang mudah difahami untuk menerima dan menghantar mesej.

02

Event Handling

Urus command, text, callback query dan pelbagai jenis update.

03

Middleware

Susun proses bot menggunakan middleware yang fleksibel.

i
Learning Note

Telegraf bukan bahasa pengaturcaraan. Ia merupakan framework yang dibina menggunakan JavaScript untuk Node.js.

GETTING STARTED

Installation

02 / 10

Sebelum menggunakan Telegraf, pastikan Node.js dan npm telah dipasang pada peranti anda.

Step 01 — Create Project

Buka terminal dan cipta folder projek baharu.

TERMINAL

YOUR FIRST PROJECT

First Bot

03 / 10

Sekarang kita akan membina Telegram Bot pertama menggunakan Telegraf.

Basic Bot Example

JAVASCRIPT
const { Telegraf } = require("telegraf");

const bot = new Telegraf(process.env.BOT_TOKEN);

bot.start((ctx) => {
  ctx.reply("Hello! Welcome to my bot.");
});

bot.launch();

console.log("Bot is running...");

Understanding the Code

Code Explanation
require("telegraf") Mengimport Telegraf daripada package.
new Telegraf() Mencipta instance bot baharu.
bot.start() Mengendalikan command /start.
ctx.reply() Menghantar mesej kepada pengguna.
bot.launch() Memulakan bot.
BOT INTERACTION

Commands

04 / 10

Commands digunakan untuk membolehkan bot bertindak apabila pengguna menghantar arahan tertentu.

bot.command()

Mengendalikan command Telegram seperti /help dan /about.

JAVASCRIPT
bot.command("help", (ctx) => {
  ctx.reply("Here is the help menu.");
});

bot.command("about", (ctx) => {
  ctx.reply("This bot was built with Telegraf.");
});

bot.hears()

Mengesan teks tertentu yang dihantar oleh pengguna.

JAVASCRIPT
bot.hears("hello", (ctx) => {
  ctx.reply("Hello there!");
});

bot.on()

Menerima jenis update tertentu seperti mesej teks.

JAVASCRIPT
bot.on("text", (ctx) => {
  ctx.reply(`You said: ${ctx.message.text}`);
});
CORE CONCEPT

Context (ctx)

05 / 10

Context atau ctx ialah objek yang diberikan oleh Telegraf kepada handler. Ia mengandungi maklumat berkaitan update yang diterima.

Telegram Update Incoming message
↓
Telegraf Handler Processes the update
↓
ctx Object Message · User · Chat · Telegram

Common Context Properties

JAVASCRIPT
bot.on("text", async (ctx) => {
  console.log(ctx.from);
  console.log(ctx.chat);
  console.log(ctx.message);
  console.log(ctx.message.text);

  await ctx.reply("Message received!");
});
Property Purpose
ctx.from Maklumat pengguna yang menghantar update.
ctx.chat Maklumat chat semasa.
ctx.message Maklumat mesej yang diterima.
ctx.telegram Interface untuk berinteraksi dengan Telegram API.
ctx.reply() Membalas mesej dalam chat semasa.
USER INTERFACE

Keyboard

06 / 10

Telegraf menyediakan Markup untuk membina keyboard dan butang interaktif.

Inline Keyboard

JAVASCRIPT
const { Markup } = require("telegraf");

bot.command("menu", (ctx) => {
  ctx.reply(
    "Choose an option:",
    Markup.inlineKeyboard([
      [
        Markup.button.callback("Profile", "profile"),
        Markup.button.callback("Help", "help")
      ]
    ])
  );
});

bot.action("profile", (ctx) => {
  ctx.answerCbQuery();
  ctx.reply("Your profile.");
});
INTERFACE PREVIEW
Choose an option:
Profile Help

Reply Keyboard

JAVASCRIPT
bot.command("keyboard", (ctx) => {
  ctx.reply(
    "Select a button:",
    Markup.keyboard([
      ["Profile", "Settings"],
      ["Help"]
    ]).resize()
  );
});
ADVANCED CONCEPT

Middleware

07 / 10

Middleware ialah fungsi yang dijalankan dalam pipeline sebelum sesuatu update sampai kepada handler seterusnya.

Update
→
Middleware
→
Handler

Basic Middleware

JAVASCRIPT
bot.use(async (ctx, next) => {
  console.log("Update received");

  await next();
});

bot.start((ctx) => {
  ctx.reply("Welcome!");
});
i
Understand next()

await next() membenarkan pipeline diteruskan kepada middleware atau handler seterusnya. Tanpanya, pipeline boleh berhenti pada middleware tersebut.

RELIABILITY

Error Handling

08 / 10

Error handling membantu developer mengesan dan mengurus ralat yang berlaku semasa bot sedang berjalan.

Using bot.catch()

JAVASCRIPT
bot.catch((err, ctx) => {
  console.error("Bot error:", err);
  console.error("Update:", ctx.update);
});

Graceful Shutdown

JAVASCRIPT
process.once("SIGINT", () => {
  bot.stop("SIGINT");
});

process.once("SIGTERM", () => {
  bot.stop("SIGTERM");
});

Quick Reference

09 / 10

Senarai method Telegraf yang biasa digunakan. Cari nama method untuk mendapatkan penerangan ringkas.

⌕ SEARCH
Method Category Description

bot.stop() System Stops the bot.
